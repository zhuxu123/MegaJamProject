# 超级巨星：四关独立摄影流程与 3D 布景初版

2026-11-15。按《剧本全.docx》将现有交付图接入项目；原有第一关、第二关及两张地图不作替换。现已支持剧情预演、相机构图、拍照确认、三图剪辑和本地发布；尚未为完整剧本编写独立的信任/关注度评分规则，不能套用原两关评分宣称通关。

当前玩家流程：**选关 → 摄制任务单 → 拍摄现场 → 选3张编辑发布 → 本关报纸**。四关均可直接开启；两个间幕随第一、第三关保留。报纸继续按钮先打开下一关任务单，第四关结束返回选关。每关的照片、证据和时间独立，详见 [四关配置与验证](Levels-20261115.md)。

第二轮回传已接入：78条动画（含21条人物表情）、1168张新透明帧，全部保持5 FPS。当前注册112条/1471帧，其中91条用于剧情、21条旧原型保留退役。回传表情使用人物帧，替代本模式的2D表情占位；原有两关不变。当前时长为40.6 / 93.6 / 71.0 / 55.2秒，详见 [第二轮动画接入](Round2-Integration-20261115.md)。下方“本次接入”和“素材缺口”是首批记录，当前回传覆盖范围以新记录为准。

## 进入与操作

运行项目，在原主菜单按 **3** 或点击 **超级巨星 · 四关独立选关**。

| 操作 | 效果 |
| --- | --- |
| 空格 / R / 鼠标右键 / 播放按钮 | 播放、暂停 |
| 按住 ←/Z、→/C | 3倍倒放、快进，可跨段；松键恢复此前播放/暂停状态 |
| PageUp / PageDown / 上下段按钮 | 切换剧情段落 |
| F1、F2、F3、F4 | 打开对应关卡任务单，清空本轮照片与证据 |
| 1、2、3 | 正面、左侧、右侧机位，平滑切换 |
| WASD / 在画面内按住左键拖动 | 调整水平与垂直构图 |
| Q/E / 滚轮 | 拉远、拉近；相机FOV变焦 |
| Enter | 拍照；确认界面再次Enter或Y保留，N/Backspace重拍 |
| Tab | 打开相册/返回摄影，最多保留6张、选3张发布 |
| Home / End / 本段重播按钮 | 本关起点 / 终点 / 当前段落起点 |
| 按住拖动进度条 | 本关连续定位；松手暂停，镜头不跟随拖动；动作按时间确定性求值 |
| B / 参考图按钮 | 在独立 3D 布景和原始参考图片之间切换 |
| 第四幕证据卡 | 点击或拖动选择，再点发送；也可 V 选择、再次 V 发送 |
| ESC / 返回按钮 | 现场返回四关选择；照片界面先返回上一级 |

未发送证据时自动播放停留在对应段落；可在本关内定位补拍。第四关须发送全部3份证据才可发布本关报纸。关尾自动打开相册，Tab可返回回看补拍；不会跨入下一关。

相册：1–6或点击原片选入/移除，点击槽位或C选择裁切对象，WASD调整裁切中心，Q/E裁切缩放，Z/X交换顺序，T切标题，P预览，Enter发布。裁切不会显示原图外的内容。发布为本地生成图片和记录，不向网络或他人发送。照片与每次发布的独立版本在 `Saved/SuperstarPhotos/`。6张用完可返回选关重开本关；重拍拒绝不占名额。参考图对照与报纸信息页不开放快门。

表情使用 `head_anchors.json` 的1471个逐帧头顶锚点（含静态母版及退役保留项）；3D模式按精灵实际变换及当前相机投影，参考图模式按同一帧与镜像换算。跌倒/起身、移动、变焦不再使用固定屏幕高度。越出取景框的符号隐藏，避免钉在画面边缘。替换动画后运行 `python Tools/Build-SuperstarHeadAnchors.py` 并检查锚点；提取器优先采用交付的逐帧anchors.json；已有烘入雨伞的片段不再把伞顶误认成人物头顶，旧素材才使用轮廓推导。

摄影与表情验证：原生Editor构建成功；`-SuperstarPhotoSmoke` 在实际渲染中覆盖拒绝、三个机位取景、三张保存、选片、排序、裁切、预览和发布。`Tools/Validate-SuperstarPhotos.py <publication.json>` 验证发布图逐像素等于原图对应裁切。日志在 `Saved/Logs/Agent-Photography-*.log`，玩法回归9/9通过。桌面键鼠验证工具启动失败，未将自动状态流程等同于手动键鼠验收；未重新打包发布版。

## 验证方式

按根目录 AGENTS.md 构建 Editor 并运行原有 AngelScript 测试，再运行资源验证器。

```powershell
& $EditorCmd $ProjectFile '/Game/levels/MainMenu?game=/Script/MegaJamProject.SuperstarStoryGameMode' -game -unattended -nosound -windowed -ResX=1280 -ResY=720 -RenderOffscreen -SuperstarSmoke
```

预演 smoke 逐段渲染全部 39 段，并验证证据未选择时不能发送、选择后可以发送。末尾日志必须出现 `SuperstarStory smoke PASS: 39 beats`，退出码必须为 0。图片参考模式增加 `-SuperstarReferences`。

从原主菜单验证入口时，URL 使用 `/Game/levels/MainMenu`，参数改为 `-SuperstarMenuSmoke`；它会通过新增的 AS 绑定进入独立模式，再完成同样的逐段检查。

截图位置为 `Saved/Screenshots/Superstar3D/`、`Saved/Screenshots/SuperstarReferences/`。这些文件不随 Git 保存。自动渲染和内部交互状态检查不等于真人鼠标、拖动、完整时长观看和打包版验收。
