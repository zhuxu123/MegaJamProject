# 2026-11-15 UI文字适配与动画补件

## 改动

超级巨星原先按固定字号、固定左偏移画按钮文字，中文回退字体及英文快捷键组合容易超过110/160/180像素按钮。现在使用Canvas实际字体对应的FontMeasure，按按钮内宽和高度调整字号，保留8像素水平、5像素垂直内边距并居中；极小窗口使用最后的等比缩放防止越界。按钮的原矩形与点击区域不变，鼠标转换仍与1280×720设计坐标一致。

覆盖播放/暂停、前后段、重播、参考图切换、返回菜单、证据发送、拍照确认/重拍和相册预览/发布/继续拍摄。剧情说明、注意事项、时间线提示和状态行分别限制在自己的区域内。相册槽位标签增加独立底色，选满3张后更新提示，避免继续显示旧的“请先选满”。

修改位于SuperstarStory.h/.cpp、SuperstarPhotography.cpp、SuperstarTransport.cpp；未改地图、原两关脚本、相机/快门/时间线输入契约或当前美术素材。

第二批动画ZIP包含78项补做任务、21项表情、当前素材和逐项提示词；当前8段回传动画复用，小北跌倒增加表情/姿态修复，C07跺脚接触事件单独复核，苏瑶跪姿表情改依赖current C08。具体任务和生成流程见 [动画补件说明](Animation-Round2-20261115.md)。
