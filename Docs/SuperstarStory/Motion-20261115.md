# 走路、转向与持物修复

这次修复针对上一版站姿平移、倒着走、雨伞悬空和手机远离人物的问题。所有原场景、原地图和历史素材保留。

## 已实现

- 林晚、小北、苏瑶、陈默、小周、女主演员各增加一个6帧走路循环，继续5 FPS；移动段落统一选择走路帧，停步后恢复对应姿态。男女路人和抱资料跑步复用原循环。
- 朝向根据移动方向与素材自身朝向计算，3D人物、参考图和表情使用相同结果；不再靠每段手填镜像决定移动朝向。
- 增加林晚持物、林晚举手机、小北持物、苏瑶持花四张姿态。逐帧手部像素锚点与道具握点在同一空间对齐，镜像、转角、换机位和跳转时间都重新计算。
- 雨伞、手机、刀、花和文件改为手部附着。伞和刀绕握点转动，避免遮住脸；人物指尖遮挡握柄。玫瑰缩小。递伞按剧情时刻切换持有人，林晚接伞后再走。
- 新生成透明手机与一体式手机直播支架。直播支架摆在林晚前方约130个设计坐标单位处，手机与夹具已画成完整组件。
- 按剧本补齐“李谋抱小北”“李谋和苏瑶喝酒”两张证据图，与原名单图一起接入证据选择和发送流程。

当前注册37项、347帧；新增40帧=36张走路帧+4张持物姿态。它们是生成的2D精灵，不是骨骼动画。动画没有参考图到动作的前导过渡。

## 数据与再生成

生成使用内置 imagegen。11张原始生成图、哈希和提示词保存在 `ArtSource/SuperstarMotion20261115/`；项目使用的帧在 `Content/SuperstarStory/Animations/Motion20261115/`，四张物品/证据图在 `Content/SuperstarStory/Static/Motion20261115/`。

`Tools/Prepare-SuperstarMotion.py --source ArtSource/SuperstarMotion20261115` 将网格图分帧、等比缩放并对齐脚底 `(320,570)`，保留透明通道；不是绘制替代人物的程序。人物身份来自对应的原参考帧。手部点按生成图人工测量，再随同分帧变换。运行 `Tools/Build-SuperstarHeadAnchors.py` 重建头顶点。

`Tools/Configure-SuperstarMotion.py` 记录本次段落配置。字段契约：

| 字段 | 含义 |
| --- | --- |
| actor.walk_clip | 移动期间使用的循环 |
| actor.move_start / move_end | 移动开始/停止秒数，位置与动画用同一时间区间 |
| clip.screen_facing | 未镜像原图的左右朝向 |
| clip.hand_anchors | 每帧手部像素点；缺省时用actor.hand |
| prop.attach_actor / grip | 人物索引、道具纹理中的归一化握点 |
| prop.angle | 朝向未镜像时的屏幕顺时针角度，绕握点旋转 |
| prop.transfer_actor / transfer_at | 在指定时间切换持有人 |

不要将旧18项全量导入器用于覆盖扩展注册表。新生成机交付时可以替换本批循环，但须继续提供朝向、握点和头部锚点。

## 验证与限制

- Editor构建、39段剧情渲染、三张证据门槛、摄影拒绝/保存/选片/裁切/排序/预览/发布检查通过；脚本测试9/9。
- `-SuperstarMotionSmoke` 在18段生成324个样本，覆盖三个机位、左右移动、持物、切换持有人，以及先跳到末尾再回到当前时间。道具握点与手部世界坐标差须小于0.11单位（含0.1单位刻意的前后层差）。
- 六个走路循环首尾轮廓差没有异常突增：首尾差/内部最大帧差为0.42–1.08；这只是技术检查，不等于最终动画表演质量验收。实机取样与预览按5 FPS展示连续三轮步态。
- 日志在 `Saved/Logs/Agent-Motion-*.log`；运行示例沿用README，将smoke参数改为 `-SuperstarMotionSmoke`。新旧模式无地图包差异。
- 握点是2D绘制坐标，人物仍是平面精灵；递伞是关键时刻切换附着，不是手指骨骼抓握或完整双人交接动画。对白口型、拥抱、完整递刀、押送等剧情动作仍待生成；雨效未加入。
- 仍有历史旧舞台材质缺失告警，未重做打包版或真人键鼠全流程验收。

实际渲染预览：`Motion-Umbrella.gif`、`Motion-Phone.png`、`Motion-Props.png`、`Motion-Livestream.png`。原始生成图和实机画面应分开审阅，不能只凭生成图判断接入正确。
